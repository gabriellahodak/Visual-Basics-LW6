# UX/UI Lab - De Standaard Analyse

Dit project is een interactieve webpagina gebouwd met Next.js en Tailwind CSS, waarin drie artikelen van De Standaard worden geanalyseerd op basis van UX (User Experience) en UI (User Interface) principes.

## UX/UI Beslissingen

Tijdens het ontwerp en de implementatie van deze website zijn de volgende UX/UI-beslissingen genomen om een optimale leeservaring te garanderen:

### 1. Visuele Hiërarchie & Typografie
We hebben gekozen voor de **Geist** font-familie voor een moderne, cleane uitstraling. Door gebruik te maken van extra dikke koppen (`font-black`) en een ruime regelafstand in de broodtekst, creëren we een duidelijke hiërarchie die de gebruiker door de content leidt.

### 2. Witruimte (Negative Space)
Er is bewust gekozen voor royale marges en padding rondom de tekstblokken en tussen verschillende secties. Dit voorkomt 'cognitive overload' en zorgt ervoor dat de focus op de inhoud blijft liggen.

### 3. Kleurgebruik & Consistentie
Elk artikel heeft een eigen accentkleur (Blauw voor AI-Slop, Paars voor Vibecoding, Rood voor Amodei). Deze kleuren worden consistent gebruikt in de kaarten op de homepagina en de knoppen op de detailpagina's, wat bijdraagt aan de herkenbaarheid.

### 4. Component-gebaseerde Structuur
Door het gebruik van herbruikbare componenten zoals `Header`, `Footer`, `ArticleCard` en `AnalysisSection`, garanderen we een consistente interface over de gehele website en houden we de code onderhoudbaar.

### 5. Responsive Design
De website is volledig responsive ontworpen. Op mobiele apparaten worden de grid-lay-outs omgezet naar single-column views en worden de marges aangepast voor een optimale leeservaring op kleinere schermen.

## Technologieën
- **Next.js (App Router)**: Voor een snelle en SEO-vriendelijke applicatiestructuur.
- **Tailwind CSS**: Voor efficiënte en modulaire styling.
- **TypeScript**: Voor type-veiligheid en betere developer experience.
- **Lucide React / SVG Icons**: Voor heldere visuele aanwijzingen.
